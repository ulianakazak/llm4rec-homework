# Задание: Random Lunch Generator

Сделай в текущей папке простое веб-приложение Random Lunch Generator.

## Требования

- HTML, CSS и обычный JavaScript.
- Список минимум из 6 блюд.
- Кнопка Generate Lunch! выбирает случайное блюдо через Math.random().
- На странице показываются название блюда и соответствующая картинка.
- Аккуратное оформление для компьютера и телефона.
- Сайт должен открываться через index.html и подходить для GitHub Pages.

## Результат

Создай файлы проекта, README с инструкцией запуска и prompt.md с текстом этого задания.

## Итерация 2: доработка изображений

Сейчас используются эмодзи. Замени их на отдельные простые SVG-иллюстрации для каждого из 8 блюд:
- создай изображения в папке assets;
- иллюстрация должна соответствовать конкретному блюду;
- используй локальные файлы и относительные пути, чтобы всё работало офлайн и на GitHub Pages;
- добавь понятный alt-текст и одинаковый размер области изображения;
- сохрани работающий случайный выбор.

В prompt.md сохрани исходный запрос и добавь этот как вторую итерацию.
В README кратко объясни, что изменилось в изображениях.
Проверь существование всех файлов и соответствие блюд иллюстрациям.
