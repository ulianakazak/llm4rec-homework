# Random Lunch Generator

Простое веб-приложение: кнопка выбирает случайное блюдо на обед и показывает его название и иллюстрацию.

## Как запустить

Способ 1 — открыть локально:
Просто открой файл `index.html` двойным кликом в любом браузере (Chrome, Safari, Firefox). Ничего устанавливать не нужно.

Способ 2 — локальный сервер (у кого установлен Python):
```bash
python3 -m http.server 8000
```
Затем открой в браузере http://localhost:8000

Способ 3 — GitHub Pages:
1. Создай репозиторий на GitHub и запушь файлы проекта (обязательно вместе с папкой `assets/`).
2. Открой **Settings → Pages**.
3. В разделе «Branch» выбери ветку `main` и папку `/ (root)`, нажми **Save**.
4. Через пару минут сайт будет доступен по адресу `https://<твой-логин>.github.io/<имя-репозитория>/`.

## Иллюстрации

Во второй итерации эмодзи заменены на отдельные SVG-иллюстрации в папке `assets/` — по одному файлу на блюдо (`assets/borscht.svg`, `assets/pizza.svg`, `assets/spaghetti.svg`, `assets/sushi.svg`, `assets/tacos.svg`, `assets/salad.svg`, `assets/shashlik.svg`, `assets/dessert.svg`).

Что изменилось:
- вместо эмодзи в `script.js` у каждого блюда хранится путь к локальному SVG-файлу (`image`) и понятный `alt`-текст;
- страница использует относительные пути, поэтому всё работает офлайн и на GitHub Pages;
- у картинки одинаковый размер области (160×160), она подключается через `<img>` с `alt`-атрибутом для доступности;
- случайный выбор работает как раньше — `Math.random()` выбирает случайный элемент массива `dishes`.

## Как это устроено

- `index.html` — разметка страницы.
- `style.css` — оформление (адаптивное: работает на компьютере и телефоне).
- `script.js` — логика: список блюд и случайный выбор через `Math.random()`.
- `assets/` — SVG-иллюстрации блюд.

Добавить своё блюдо можно в массиве `dishes` в файле `script.js` — нужно указать `name` (название), `image` (путь к картинке в `assets/`) и `alt` (описание картинки):

```js
const dishes = [
  { name: "Борщ со сметаной", image: "assets/borscht.svg", alt: "Тарелка борща со сметаной" },
  // ... добавь ещё строки
];
```
